# 知行账号使用协议

**生效日期：2026 年 10 月 23 日**

欢迎使用知行AI、知行AI学习版、知行计算器及其相关功能（以下统称“知行产品”）。请在登录前认真阅读本协议和《知行账号隐私声明》。登录或继续使用需要账号的功能，即表示你已阅读并同意相关条款。如不同意，请不要登录或提交个人信息。

## 一、服务内容与边界

1. 知行产品提供学习辅助、知识检索、计算、函数分析、化学问题辅助、文本或图片理解及 AI 对话等功能。不同产品的功能、模型和可用性可能不同。
2. AI 内容由模型自动生成，可能存在错误、遗漏、过时信息、推理不完整或格式异常。数学、化学等结论应结合教材、教师意见、实验规范和可靠资料复核。AI 输出不是教师、专业人员或正式机构的最终判断。
3. 服务可能因维护、网络、第三方模型/API、资源限制或安全事件而暂时不可用。产品不承诺任何时候不中断、无错误或适用于所有特定用途。
4. 用户请求可能被发送给当时配置的第三方 AI 服务商处理。模型能力、数据处理地点、留存规则和服务条款由相应服务商决定。

## 二、账号、用户名与登录

1. 用户账号目前由管理端创建和管理。管理员可为账号设置唯一用户名；设置后可使用用户名和密码登录。支持的页面也可使用账号邮箱登录。
2. 用户名不区分大小写进行唯一性检查，格式为 3–24 个字符，以英文字母开头，只能包含英文字母、数字、下划线或连字符。不得使用冒充他人、违法、侮辱、侵犯他人权利或可能造成混淆的名称。
3. 用户应确保账号信息合法、准确且有权使用，不得冒用他人身份、未经授权使用他人账号或尝试收集他人的认证信息。
4. 用户应妥善保管密码，不得向他人泄露。发现密码泄露、异常登录或账号被他人使用时，应尽快停止使用受影响的会话并通过产品提供的渠道联系维护者。
5. 登录成功后，普通用户会话可能通过安全 Cookie 在知行产品相关子域之间共享，以减少重复登录。普通用户会话不具有管理员权限。管理后台必须单独、手动进行管理员认证。
6. 请勿向其他人分享账号密码、访问令牌、刷新令牌、管理凭据或任何服务端机密。

## 三、用户内容与使用责任

1. 用户应确保自己有权提交文本、图片、文件和其他内容，不得上传侵犯他人隐私、著作权、商业秘密或其他合法权益的材料。
2. 用户对自己输入的内容、使用 AI 输出的方式以及向第三方披露输出所产生的后果负责。
3. 用户不得利用产品从事违法活动、欺诈、骚扰、侵犯他人权益、传播恶意代码、攻击系统、窃取数据或其他适用法律禁止的行为。
4. 请勿将密码、证件号码、支付凭据、私人 API 密钥、未公开商业机密或其他不必要的敏感信息输入 AI 对话。为生成回答，AI 服务可能需要处理你发送的内容。
5. 上传图片或文件前，应确认其中不含不必要的个人信息、他人隐私或机密资料。识图、文件解析与自动生成内容均可能出错。

## 四、访问限制与防滥用

1. 为降低自动化滥用风险，未登录或无法通过服务端认证的对话可能受到 IP 地址、设备 Cookie 和其他安全规则限制。当前游客 AI 对话规则为：单个 IP 每 15 分钟最多 15 次；单个浏览器设备标识每 15 分钟最多 15 次。
2. 服务端核验通过的已登录账号不受上述游客对话次数限制，但这不代表服务商、网络、并发、请求大小、上下文长度或其他技术限制同时被取消。
3. 设备 Cookie 是随机浏览器标识，不是不可更改的硬件识别。清除 Cookie、更换浏览器、无痕模式或更换设备可能导致设备标识变化；系统仍可结合 IP 和其他安全信号限制滥用。
4. 如出现异常请求、账号被盗、绕过访问控制或危害服务稳定性的行为，维护者可按具体风险限制请求、暂停会话、停用账号或采取其他必要措施，并尽量避免对正常用户造成不必要影响。

2. 用户应对其输入内容拥有或取得必要权利。使用 AI 输出时，应遵守适用法律、第三方服务商条款及其他相关权利限制。AI 输出可能与其他用户所得内容相似，不保证独创性或可获得特定权利保护。
3. 服务可能依赖 Cloudflare、Supabase、GitHub Pages 以及所配置的 AI API 等第三方服务。其可用性、政策或接口变更可能影响部分功能，第三方服务各自的规则由其服务商负责。

## 六、云端数据与账号管理

1. 账号资料、云端历史和安全信息的处理方式详见《知行账号隐私声明》。
2. 管理员可能在后台创建账号、设置或清除用户名、查看账号关联的云端对话，或注销账号。注销前必须核对账号；注销可能导致账号无法再次登录，并触发关联云端数据清理。
3. 用户应在退出公共设备前退出账号。清除本机 Cookie 只会影响本机登录状态，不等于已删除服务端账号或云端历史。
4. 用户如需管理个人信息或了解数据处理方式，可使用产品当前提供的账号管理或反馈渠道；实际可办理的事项以现有功能与适用法律为准。

2. 重要学习结论、实验操作、安全决定或对外发布内容都应由用户自行核实。不得仅依赖 AI 输出进行危险实验、医疗诊断、法律决策、投资交易或其他高风险行为。
