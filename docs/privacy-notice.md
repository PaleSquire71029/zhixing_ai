# 知行账号隐私声明

**生效日期：2026 年 10 月 23 日**

本声明说明知行AI、知行AI学习版、知行计算器及相关产品（统称“知行产品”）在账号登录、AI 对话、云端历史与安全防护过程中，可能如何收集、使用、存储和共享信息。请在登录前认真阅读。

## 一、可能处理的信息

### 1. 账号和身份信息
- 账号 ID、邮箱、管理员设置的用户名、账号创建时间和最近登录时间。
- 登录请求、身份核验结果、会话状态，以及维持登录所需的认证令牌。服务端使用 HttpOnly、Secure 属性的 Cookie 管理访问和刷新会话，网页脚本无法直接读取这些 Cookie。
- 管理员执行的账号创建、用户名设置或注销等操作所需的信息。

### 2. 网络请求与安全信息
- 请求 IP、时间、来源网站、浏览器 User-Agent、请求状态、耗时，以及必要的模型与用量统计。
- 在可用时由 Cloudflare 提供的大致城市、地区、国家/地区代码或时区信息。
- 随机生成并通过 zx_device Cookie 保存的浏览器设备标识，用于统计游客的对话请求次数。它不是手机硬件序列号，不用于宣称识别不可更改的真实设备。
- 后端限流存储会对限流键做摘要处理，并按时间窗口过期清理。请求日志可能保留 IP、地理位置、来源、User-Agent、状态、模型、用量及耗时等排障字段；日志设计不应存储模型 API 密钥或完整聊天正文。

### 3. 对话和用户提交内容
- 用户主动发送的文本、图片、文件（如该功能启用）、对话上下文、AI 回复，以及云端保存和展示对话所需的关联标识。
- 为提供云端记录或多产品历史功能，对话可能与登录账号 ID 关联；记录可以按产品分类，并由授权管理员统一管理。

请勿提交不必要的敏感信息，例如密码、证件号码、支付信息、私人 API 密钥或第三方机密。

## 二、信息的使用目的

相关信息可能用于：创建和验证登录会话、确认账号归属、在支持的知行产品之间共享普通用户登录状态；处理 AI 请求、显示回答、保存或同步用户启用的云端对话功能；统计请求与模型用量、排查网络故障和服务商错误；识别异常请求并实施限流；保护账号、验证后台权限和调查安全问题；响应数据管理请求；遵守适用法律法规或保护相关人员的合法权益。

## 三、Cookie 与跨产品登录

1. 登录成功后，服务端可能设置 zx_access 与 zx_refresh 两个 HttpOnly、Secure、SameSite=Lax Cookie，并将它们限定在知行相关子域使用，以便产品之间共享普通用户登录状态及刷新会话。
2. 游客设备 Cookie zx_device 用于请求次数统计。页面显示“已登录”或单纯提交一个用户 ID 本身不构成认证；服务端会验证会话。
3. 普通用户登录不会自动登录管理后台。管理后台需要单独、手动输入管理员凭据，并使用独立权限会话。
4. 清除 Cookie、使用无痕模式、更换浏览器或设备可能导致登录失效或生成新的设备标识。清除 Cookie 不会自动删除服务端账号或云端对话。

## 四、存储和第三方服务

1. 静态页面可能由 GitHub Pages 等平台托管；API 与安全逻辑由 Cloudflare Workers 处理；账号认证和云端数据可能由 Supabase 提供。
2. 用户发送 AI 请求时，服务端会把生成回答所必需的内容发送到当前配置的 AI API 服务商。实际服务商、处理地区、数据保留方式和用途取决于当时配置以及服务商政策。
3. 为完成服务，相关数据可能由这些第三方在其基础设施中处理，数据所在地区可能不同于用户所在地。第三方服务商对自身系统的数据处理遵循其各自的条款和隐私政策。
4. 管理后台会向获得授权的管理员展示完成账号管理、云端历史管理、故障排查和安全审计所需的信息。应依照最小必要原则访问和处理这些数据。
5. 产品不以向广告商出售用户个人信息为服务目的。为提供服务、运维、安全、用户授权或遵守法律而发生的必要处理不属于广告销售。

## 五、信息保存和删除

1. 账号信息会在账号存续期间按身份认证和账号管理需要保存。注销账号时，系统会尝试删除对应的认证账号、用户名映射和关联云端记录；第三方备份或依法必须保留的记录可能无法立即从所有系统清除。
2. 云端对话是否保存取决于用户所用功能和产品配置。管理端具有云端记录管理及清理能力，并可能按超过 90 天未活跃的规则清理过期会话；实际清理结果以系统执行状态为准。
3. 请求日志、限流记录和审计记录按安全、排障或管理用途保存，并受系统上限或过期机制约束。用户名索引、注册来源和其他必要的元数据可能保存在 Durable Objects 等后端存储中。
4. 用户可通过产品现有功能管理自己可访问的对话，或通过已有账号管理/反馈渠道提出信息处理请求。具体可执行范围取决于身份核验、现有功能和第三方系统能力。
5. 删除浏览器本地记录不会自动删除云端数据；删除云端数据也不会自动删除用户自行下载、转发或复制的内容。

## 六、数据安全

1. 服务端凭据、模型 API 密钥和 Supabase 高权限密钥不应进入公开前端代码或公共仓库，而应由后端 Secret 管理。
2. 系统使用来源校验、登录与请求限流、角色权限检查、敏感配置加密和安全响应头等措施降低风险。任何技术措施都不能保证绝对安全。
3. 用户应妥善保管密码、避免共享已登录设备，不向他人透露会话信息，并在公共设备结束使用后退出账号。
4. 如怀疑账号被盗或信息出现异常披露，应停止使用受影响的会话并通过产品可用渠道联系维护者。排查安全事件时，可能需要处理有限的账号、请求和日志信息。

## 七、未成年人及第三方个人信息

1. 未成年人应在监护人指导下阅读和遵守本声明与账号使用协议。
2. 未经合法授权，不应上传他人的私人对话、证件、照片、联系方式或其他个人信息。若所提交材料包含他人信息，提交者应确认具有合法处理依据。

## 八、用户选择与相关权利

用户可以选择不登录、不使用云端历史，或避免提交可识别个人的信息。浏览器可清除 Cookie，但这仅影响当前浏览器状态，不等于完成服务端删除请求。用户对账号信息、云端历史或隐私处理有疑问时，可使用产品当前提供的账号管理或反馈功能提出请求。查询、更正、删除或其他权利会根据适用法律及实际服务能力处理。

本声明可能因产品功能、安全措施、服务商或法律要求而更新。最新版本会在本页面发布并标注日期；重大变化会在合理范围内提示。继续使用需要同意的功能，表示用户接受更新后的声明。
